# Productivity

- [`bro`](../reference/productivity/bro.md) — restate the last message in plain
  language. Type it explicitly; it never fires on its own.
- [`grill-me`](../reference/productivity/grill-me.md) — get interviewed about a loose
  idea until you could commit to it. Type it explicitly; works on anything, not just
  code, and writes no files.
- [`grilling`](../reference/productivity/grilling.md) — the interview primitive
  `grill-me` and `grill-with-docs` run; fires on its own when you ask to be grilled.
- [`unslop`](../reference/productivity/unslop.md) — cut AI tells from any writing.
  Applies by default to prose this repo produces.

That's the guide. See `docs/reference/` for what each skill actually does in more
depth, or `AGENTS.md` for the full routing rules.
