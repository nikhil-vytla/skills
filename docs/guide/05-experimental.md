# Experimental

- [`papercuts`](../reference/experimental/papercuts.md) — log small frictions to a
  per-repo `PAPERCUTS.jsonl` via the bundled `papercut` CLI as they happen. Repos opt
  in with `papercut init`; the whole-session `/papercuts` sweep only runs when typed.

That's the guide. See `docs/reference/` for what each skill actually does in more
depth, or `AGENTS.md` for the full routing rules.
