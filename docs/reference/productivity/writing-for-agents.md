# writing-for-agents

## What it does

Reference for writing any document an agent consumes: a skill, an `AGENTS.md` or
`CLAUDE.md`, or a doc reached by a pointer. It covers context pointers (wording decides
when the agent reaches material), the context-load versus cognitive-load budgets, and,
in `SKILL-MECHANICS.md`, frontmatter, invocation choice, and router skills.

## When to reach for it

Creating or editing a skill, or modifying `AGENTS.md` or `CLAUDE.md`. Model-invoked;
`retro` calls it.
