Add `clean-copy` to `experimental/`: model-invoked cleanup of interface copy that
shouldn't exist — captions restating a label, hints pre-empting a worry the user never
had, warnings that are scar tissue from a fixed bug. Walks each string down a ladder
(surface at all → label needs it → pre-empting a non-worry → rewrite or delete) and
keeps only copy the user genuinely cannot act without. Ported verbatim from a paste at
`paste.rachel.systems` (no upstream license given, so only `metadata.source` is set).
